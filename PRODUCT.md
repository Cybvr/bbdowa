# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

BBDO West Africa team members use the site to understand the agency, its people, workflows, products, and project work. The Projects surface lets visitors scan live and completed work and open an individual project for its case-study narrative.

## Product Purpose

BBDOWA Chaos is a shared web home for BBDO West Africa information and working knowledge. The Projects section makes agency work browsable as project records rather than as a client-account list.

## Operating Context

Projects are explored from a filterable table and opened as individual detail pages. Project narratives follow this fixed sequence: Challenge, Insight, Strategy, Platform, Execution, and Outcome. In this context, Platform means the channels used, such as television, radio, digital, social, experiential, and out-of-home.

## Capabilities and Constraints

- The existing implementation is a dependency-free static HTML, CSS, and JavaScript site.
- Project filters are All, Live, and Completed.
- Each project needs a rounded-square table image and a detail-page image.
- The user will provide final project images; a neutral placeholder is required until then.
- Project data must be centralized so records and images can be replaced without rewriting page markup.

## Brand Commitments

Preserve the incumbent BBDO West Africa name, logo, direct uppercase voice, red/black/cream identity, and existing site navigation behavior.

## Evidence on Hand

- Existing brand logo: `bbdo-west-africa.png`.
- Existing project-adjacent account records in `clients.html`: Brown-Forman / Jack Daniel's, Keizen Games / Betano, Proforce Nigeria, and 1 Utility Bank.
- Existing product list/detail patterns in `products.html`, `product.html`, and `content.js`.
- Final project images and case-study copy have not yet been supplied. The interface must not fabricate Challenge, Insight, Strategy, Execution, or Outcome claims.

## Product Principles

- Make project status and ownership easy to scan.
- Move from overview to detail without losing context.
- Keep unconfirmed project evidence visibly provisional.
- Make future content and image replacement straightforward.
- Preserve accessible, responsive navigation and reading order.
