# Projects surface

- Scope and mode: `projects.html` is an Operate index for scanning project status; `project.html` is a Read detail surface for understanding one case study.
- Audience and job: BBDO West Africa team members need to find live or completed work quickly, then understand the project from Challenge through Outcome.
- Content and constraints: status filters are All, Live, and Completed; Platform means channels; final images and case-study evidence are user-supplied, so neutral placeholders must remain visibly provisional.
- Direction: extend the incumbent BBDO red, black, cream, uppercase, rule-led visual system. The memorable moment is the rounded-square project image moving from compact table thumbnail to the detail-page hero.
- Interaction: rows open hash-addressed project details; tabs support mouse and keyboard navigation; an empty Completed state explains why no records appear.
- Unresolved: final project titles, images, channel lists, and case-study copy await user content.
